# Summary

ATAP (ATAP Terrain-Aware Architectural Polygonization) is an open-source
GIS-native framework for deriving hierarchical, terrain-referenced building
mass representations from authoritative building footprints and elevation
surfaces.

ATAP investigates whether useful three-dimensional building-mass complexity can
be represented canonically using ordinary GIS polygon geometry, hierarchical
relationships, and vertical semantics while leaving explicit surface generation
to downstream rendering systems.
