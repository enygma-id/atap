# Security Policy

## Reporting a Vulnerability

Please do not disclose a suspected vulnerability publicly before maintainers
have had a reasonable opportunity to investigate.

Use GitHub private vulnerability reporting once enabled, or an official
Enygma-designated private security contact.

Do not include credentials, private datasets, production secrets, or personal
data in public Issues.

## Scope

Relevant security issues may include:

- arbitrary code execution;
- path traversal;
- unsafe archive/file handling;
- malicious raster or vector input handling;
- denial-of-service through crafted geometry;
- command injection;
- dependency or supply-chain compromise;
- credential leakage.

## Supported Versions

A formal supported-version matrix will be published when ATAP begins stable
tagged releases.
