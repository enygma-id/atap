# Code of Conduct

ATAP contributors, maintainers, researchers, users, and institutional
participants are expected to interact professionally and respectfully.

The project does not tolerate harassment, threats, discriminatory abuse,
doxxing, malicious disruption, or knowingly false claims of authorship or
provenance.

Technical disagreement is expected and should be resolved through evidence,
reproducible results, code review, and documented reasoning.

Maintainers may moderate project spaces when conduct creates material risk to
contributors, users, project security, research integrity, or project
operations.
