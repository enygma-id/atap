# AI and LLM Usage

## Scope

ATAP uses AI/LLM systems as development and research-assistance tools.

The project records this use from the beginning so that human responsibility
and machine assistance remain clearly separated.

## Human Origin

The ATAP problem, motivation, research direction, design principles, and
acceptance criteria originated from the human project team through real
geospatial and digital-twin work.

These needs were not generated by an LLM.

## LLM-Assisted Work

LLM systems have been used to assist with:

- coding acceleration;
- refactoring suggestions;
- debugging;
- comparison of computational approaches;
- mathematical and physical formulation exploration;
- documentation drafting;
- software-architecture discussion;
- prior-art discovery assistance;
- structured technical comparison;
- experimental implementation.

## Human Validation

LLM output is not treated as authoritative.

Suggested code, formulas, methods, or documentation may be accepted, modified,
rejected, replaced, experimentally tested, or rolled back.

Human contributors remain responsible for:

- problem definition;
- research questions;
- canonical data-model decisions;
- algorithm selection;
- validation;
- scientific interpretation;
- stable vs experimental status;
- licensing;
- novelty claims;
- publication claims;
- final software acceptance.

## Authorship

LLM systems are tools.

They are not recognized as founders, scientific authors, copyright holders,
maintainers, project stewards, or accountable decision-makers.

## Working Principle

> **Human-originated, AI-assisted, human-validated.**

## Publication Disclosure

Any publication should include an AI-usage disclosure consistent with the
venue's current policy and the actual tools used during the work.
