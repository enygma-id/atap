# Roadmap

This roadmap describes direction, not a commitment to dates or guaranteed
features.

## Repository and Research Foundation

- public repository;
- licensing and governance;
- reproducible project structure;
- testing and CI;
- reference data and examples;
- public Issues and Pull Requests;
- tagged releases.

## Stable GIS-Native Mass Decomposition

- authoritative footprint input;
- DSM + mandatory DTM;
- terrain normalization;
- hierarchical mass decomposition;
- GeoJSON output contract;
- geometry validation;
- reference viewer/examples.

## Scientific Validation

- multiple building typologies;
- sensitivity testing;
- failure-case catalog;
- comparison with higher-fidelity references;
- parameter analysis;
- runtime and memory benchmarks.

## Packaging and Integrations

- Python package/API;
- CLI;
- GeoPackage/PostGIS workflows;
- renderer examples;
- schema documentation.

## Research Extensions

Potential directions:

- point-cloud input;
- LAS/LAZ;
- roof surfaces;
- ridge/eave semantics;
- richer void handling;
- GIS-native LoD2.x-style representation.

Experimental capabilities enter the stable profile only after validation.
